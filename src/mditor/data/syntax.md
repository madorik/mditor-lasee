# MDitor 문서 문법

MDitor 문서는 Markdown 이다. 일반 Markdown 뷰어로 열어도 읽히고, MDitor 는 같은 글을 보고서 모양으로 그려 PDF 로 낸다.
사람과 AI 가 같은 MD 를 고친다.

## 뼈대

````
# 문서 제목                 ← 맨 첫 줄에 한 번(없어도 된다)

## 1. 섹션 제목             ← 큰 제목. 섹션을 나눈다

### 블록 제목               ← 작은 제목. 바로 아래 본문 하나와 한 덩어리(블록)가 된다
본문 문단

- 목록 항목
  - 하위 항목(위 항목의 글자 위치 이상으로 들여 쓴다, 3단계까지)

1. 번호 항목
- [ ] 할 일 항목

```py
코드 블록
```

---

| 머리글 | 머리글 |
|:---|---:|
| 칸 | 칸 |
> 비고(블록 맨 아래에 작은 글씨로 붙는다. 줄마다 하나)

![그림 설명](그림이름.png)
````

- **블록** = (제목 `###`) + 본문 하나(문단 / 목록 / 표 / 그림 / 코드 블록 / 가로줄 / 쪽 나눔) + 비고(`>`). PDF 에서 블록은 쪽이 넘어갈 때 통째로 다음 쪽으로 간다.
- 제목 없이 본문만 써도 블록이 된다. 문단은 한 줄이 한 문단이다. 블록 사이는 빈 줄 하나로 띄운다.
- `####` 이하 제목은 `###` 로 읽는다.

## 목록

- 글머리 `-` `*` `+`, 번호 `1.` `1)`(숫자 아홉 자리까지). 번호는 `1.` 꼴로 다시 써서 저장한다. 같은 단계에서 이어진 번호 항목은 첫 번호부터 1씩 이어 센다 — `3.` 으로 시작하면 3, 4, 5…
  (글머리 항목이 끼면 그 뒤 번호는 새로 시작한다).
- **할 일**: `- [ ] 할 일`, `- [x] 끝낸 일`(번호 항목에도 `1. [ ] …`). PDF 에는 □ ■ 로 나온다.
- 하위 항목은 위 항목의 글자 위치(`- ` 는 2칸, `1. ` 는 3칸) 이상으로 들여 쓴다. 최대 3단계 — 그보다 깊으면 3단계로 읽는다. 앞 항목보다 한 단계씩만 깊어진다.

## 코드 · 가로줄 · 쪽 나눔 · 정렬

- **코드 블록**: 백틱 세 개 이상(`` ``` ``)으로 감싼다. 여는 줄 뒤에 언어 이름을 쓸 수 있다(`` ```py ``). 안의 글은 서식 없이 그대로고,
  빈칸·줄바꿈이 보존되며 PDF 에서는 고정폭 글자로 긴 줄은 꺾인다. 안에 백틱 세 개가 있으면 더 긴 울타리(네 개)로 감싼다.
  닫는 울타리가 없으면 문서 끝까지가 코드다. **코드 안의 `#`·`##` 줄은 제목이 아니다.** 들여쓰기는 0~3칸까지 울타리로 읽는다.
- **가로줄**: `---` `***` `___` 한 줄. 글자 그대로 쓰려면 `\---`.
- **쪽 나눔**: `<!-- pagebreak -->` 한 줄. 그 자리에서 다음 쪽으로 넘어간다(이미 쪽 맨 위면 아무 일도 없다).
- **문단 정렬**: 문단 한 줄 전체를 정렬 태그로 감싼다 — `{가운데}…{/가운데}` `{오른쪽}…{/오른쪽}` `{양쪽}…{/양쪽}`
  (`{왼쪽}` 은 기본이라 지워진다). 문단 일부만 감싼 정렬 태그나 표·목록·제목 안의 정렬 태그는 뜻이 없어 지워진다.
  영어 이름은 `{center}` `{right}` `{justify}` `{left}`.
- 번호·기호로 읽히는 문단을 글자로 쓰려면 앞에 `\`: `1\. 개요`, `\- 항목`, `\# 제목`, `\<!-- pagebreak -->`, `\___`.

## 글 서식

| 쓰기 | 뜻 |
|:---|:---|
| `**굵게**` | 굵게 |
| `~~취소선~~` | 취소선 |
| `{기울임}글{/기울임}` | 기울임 |
| `{빨강}글{/빨강}` `{파랑}글{/파랑}` `{회색}글{/회색}` | 글자 색 |
| `{밑줄}글{/밑줄}` | 밑줄 |
| `{음영}글{/음영}` | 글자 배경(회색) |
| `==형광펜==` | 노란 형광펜 |
| `[글](https://주소)` | 링크 |
| `` `코드` `` | 고정폭 글자(안은 서식 없이 그대로) |
| `H<sub>2</sub>O` `x<sup>2</sup>` | 아래 · 위 첨자 |
| `<br>` | 항목·칸·문단 안 줄바꿈 |

- `**` `~~` `==` 는 여는 기호 **뒤**와 닫는 기호 **앞**이 공백이 아니어야 짝이 된다. `** 글 **` 은 서식이 아니다.
- 짝 없는 기호는 글자 그대로 남는다(각주 `1.31**`).
- 서식은 겹쳐 쓸 수 있다(링크 글 안의 `**굵게**` 등). 링크 안에 링크는 없다. 링크 주소는 공백·괄호가 없어야 한다(괄호는 한 겹까지 짝이 맞으면 된다 —
  `https://ko.wikipedia.org/wiki/함수_(수학)`). 공백이 든 주소는 `%20` 으로 쓴다. 주소가 `http` `https` `mailto` `tel` 인 링크만 PDF 에서 눌린다.
- 코드는 같은 개수의 백틱으로 닫는다. 코드 안에 백틱이 있으면 더 많은 백틱으로 감싼다: ``` ``a`b`` ```. 닫는 짝이 없으면 백틱은 글자다.
- 기호를 글자로 쓰려면 앞에 `\` 를 붙인다: `\*\*`, `\{빨강}`, `\<br>`, `\[`, `` \` ``, `\=\=`.
- 태그는 영어 이름도 같다: `{red}` `{blue}` `{gray}` `{italic}` `{underline}` `{shade}` (= `{빨강}` `{파랑}` `{회색}` `{기울임}` `{밑줄}` `{음영}`),
  정렬은 `{left}` `{center}` `{right}` `{justify}` (= `{왼쪽}` `{가운데}` `{오른쪽}` `{양쪽}`). 한 문서는 한 가지 이름으로 쓴다 — 문서에 처음 나오는 태그의 이름을 따르고, 섞여 있으면 그 이름으로 맞춘다.
- 제목(`#` `##` `###`)에도 서식을 쓴다. 제목은 한 줄이라 `<br>` 은 빈칸이 된다. 그림 설명에는 서식을 쓰지 않는다. 표 칸·비고·목록 항목에도 쓴다.

## 표

```
| 분야 | 매출(백만 원) | < | 비중 |
| ^ | 종이책 | 전자책 | ^ |
|:---|---:|---:|:---:|
| 문학 | 412 | 96 | 27.6% |
| 기타 | {음영}184{/음영} | 40 | 12.2% |
```

- 구분선(`|---|`) **위**가 머리글이다. 머리글은 여러 줄일 수 있고, 쪽이 넘어가면 다음 쪽에 다시 나온다.
- 구분선으로 열 정렬을 정한다: `:---` 왼쪽, `:---:` 가운데, `---:` 오른쪽.
- **칸 합치기**: 칸에 `<` 만 있으면 왼쪽 칸과, `^` 만 있으면 위 칸과 합친다. 행마다 칸 수는 그대로 둔다.
  머리글과 본문은 따로 합친다. 합친 모양이 직사각형이 아니면 합쳐지지 않는다.
- **칸 배경**: 칸 내용 전체를 `{음영}…{/음영}` 으로 감싼다.
- 칸 안의 `|` 는 `\|`, 줄바꿈은 `<br>`. `<` 나 `^` 한 글자만 든 칸을 글자로 쓰려면 `\<`, `\^`.
- **칸 안의 그림**: 칸 글 안에 `![설명](이름)` 을 쓴다. 뒤에 `{width=40%}` 를 붙이면 칸 폭의 40% 로 그린다(1~100).
  그림은 칸 안에서 한 줄을 차지하고(앞뒤 글은 그림 위 · 아래 줄로 간다), 가로 자리는 열 정렬을 따른다. 설명은 칸에 나오지 않는다.
  칸 안에서 `![` 로 시작하는 글을 그림이 아닌 글자로 쓰려면 `\![`.
- 모든 행의 칸 수는 머리글과 같아야 한다(모자라면 빈 칸으로 채우고, 넘치면 오류).

## 그림

`![설명](이름)` 을 한 줄에 혼자 쓴다. 이름은 문서에 붙인 그림의 이름이다. 설명은 그림 아래에 나온다.
뒤에 `{width=60%}` 를 붙이면 본문 폭의 60% 로 그린다(1~100, 작은 그림도 그 폭까지 키운다). 없으면 원래 크기(본문 폭 · 쪽 높이 안).

```
![매출 추이](chart.png){width=60%}

| 상품 | 사진 |
|:---|:---:|
| 책갈피 | ![책갈피](bookmark.png){width=50%} |
```

## 쪽

- 쪽은 PDF 를 실제로 그려 본 결과로 정해진다. 화면 미리보기의 'n쪽' 경계는 PDF 와 같다.
- 블록은 남은 자리에 안 들어가면 통째로 다음 쪽으로 간다. 한 쪽보다 큰 표는 행 단위로 나뉘고 머리글이 반복된다. 한 쪽보다 긴 코드 블록은 줄 단위로 나뉜다.
- `<!-- pagebreak -->` 는 그 자리에서 쪽을 넘긴다(빈 쪽은 만들지 않는다).
- 문서 설정에서 '섹션마다 새 쪽'을 켜면 `##` 마다 새 쪽에서 시작한다.
