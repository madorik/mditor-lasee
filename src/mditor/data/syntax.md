# MDitor 문서 문법

MDitor 문서는 Markdown 이다. 일반 Markdown 뷰어로 열어도 읽히고, MDitor 는 같은 글을 보고서 모양으로 그려 PDF 로 낸다.
사람과 AI 가 같은 MD 를 고친다.

## 뼈대

```
# 문서 제목                 ← 맨 첫 줄에 한 번(없어도 된다)

## 1. 섹션 제목             ← 큰 제목. 섹션을 나눈다

### 블록 제목               ← 작은 제목. 바로 아래 본문 하나와 한 덩어리(블록)가 된다
본문 문단

- 목록 항목
  - 하위 항목(앞 공백 2칸씩, 3단계까지)

| 머리글 | 머리글 |
|:---|---:|
| 칸 | 칸 |
> 비고(블록 맨 아래에 작은 글씨로 붙는다. 줄마다 하나)

![그림 설명](그림이름.png)
```

- **블록** = (제목 `###`) + 본문 하나(문단 / 목록 / 표 / 그림) + 비고(`>`). PDF 에서 블록은 쪽이 넘어갈 때 통째로 다음 쪽으로 간다.
- 제목 없이 본문만 써도 블록이 된다. 문단은 한 줄이 한 문단이다. 블록 사이는 빈 줄 하나로 띄운다.
- `####` 이하 제목은 `###` 로 읽는다. 번호 목록(`1.`)·코드 블록·링크 문법은 없다 — 번호는 글자로 쓴다.

## 글 서식

| 쓰기 | 뜻 |
|:---|:---|
| `**굵게**` | 굵게 |
| `~~취소선~~` | 취소선 |
| `{빨강}글{/빨강}` `{파랑}글{/파랑}` `{회색}글{/회색}` | 글자 색 |
| `{밑줄}글{/밑줄}` | 밑줄 |
| `{음영}글{/음영}` | 글자 배경(회색) |
| `<br>` | 항목·칸·문단 안 줄바꿈 |

- `**` 와 `~~` 는 여는 기호 **뒤**와 닫는 기호 **앞**이 공백이 아니어야 짝이 된다. `** 글 **` 은 서식이 아니다.
- 짝 없는 기호는 글자 그대로 남는다(각주 `1.31**`).
- 기호를 글자로 쓰려면 앞에 `\` 를 붙인다: `\*\*`, `\{빨강}`, `\<br>`.
- 제목(`#` `##` `###`)과 그림 설명에는 서식을 쓰지 않는다.

## 표

```
| 분야 | 매출(백만 원) | < | 비중 |
| ^ | 종이책 | 전자책 | ^ |
|:---|---:|---:|:---:|
| 문학 | 412 | 96 | 27.6% |
| 기타 | {음영}184{/음영} | 40 | 12.2% |
```

- 구분선(`|---|`) **위**가 머리글이다. 머리글은 여러 줄일 수 있고, 쪽이 넘어가면 다음 쪽에 다시 나온다.
- 구분선으로 열 정렬을 정한다: `:---` 왼쪽, `:---:` 가운데, `---:` 오른쪽.
- **칸 합치기**: 칸에 `<` 만 있으면 왼쪽 칸과, `^` 만 있으면 위 칸과 합친다. 행마다 칸 수는 그대로 둔다.
  머리글과 본문은 따로 합친다. 합친 모양이 직사각형이 아니면 합쳐지지 않는다.
- **칸 배경**: 칸 내용 전체를 `{음영}…{/음영}` 으로 감싼다.
- 칸 안의 `|` 는 `\|`, 줄바꿈은 `<br>`. `<` 나 `^` 한 글자만 든 칸을 글자로 쓰려면 `\<`, `\^`.
- 모든 행의 칸 수는 머리글과 같아야 한다(모자라면 빈 칸으로 채우고, 넘치면 오류).

## 그림

`![설명](이름)` 을 한 줄에 혼자 쓴다. 이름은 문서에 붙인 그림의 이름이다. 설명은 그림 아래에 나온다.

## 쪽

- 쪽은 PDF 를 실제로 그려 본 결과로 정해진다. 화면 미리보기의 'n쪽' 경계는 PDF 와 같다.
- 블록은 남은 자리에 안 들어가면 통째로 다음 쪽으로 간다. 한 쪽보다 큰 표는 행 단위로 나뉘고 머리글이 반복된다.
- 문서 설정에서 '섹션마다 새 쪽'을 켜면 `##` 마다 새 쪽에서 시작한다.
