문법 안내

MDitor 문서는 Markdown 입니다. 일반 Markdown 뷰어로 열어도 읽히고, MDitor 는 같은 글을 보고서 모양으로 그려 PDF 로 냅니다. ‘문서’ 탭에서 고치면 이 문법으로 자동으로 써지니, 외우지 않아도 됩니다.

뼈대

쓰기뜻
# 제목문서 제목. 맨 첫 줄에 한 번 씁니다(없어도 됩니다).
## 제목큰 제목. 문서를 섹션으로 나눕니다.
### 제목작은 제목. 바로 아래 본문 하나와 한 덩어리(블록)가 됩니다.
- 항목목록. 앞에 공백 2칸을 둘 때마다 한 단계 아래 항목이 됩니다(3단계까지).
> 비고블록 맨 아래에 작은 글씨로 붙는 설명. 줄마다 하나입니다.
그냥 쓴 줄문단. 한 줄이 한 문단입니다.

블록은 제목(###) + 본문 하나(문단·목록·표·그림) + 비고(>)입니다. PDF 에서 블록은 쪽이 넘어갈 때 통째로 다음 쪽으로 갑니다. 제목 없이 본문만 써도 블록이 되고, 블록 사이는 빈 줄 하나로 띄웁니다.

#### 이하 제목은 작은 제목으로 읽습니다. 번호 목록(1.)·코드 블록·링크 문법은 없습니다. 번호는 글자로 쓰면 됩니다.

둘째 줄
  • ** 와 ~~ 는 여는 기호 뒤와 닫는 기호 앞이 공백이 아니어야 짝이 됩니다. ** 글 ** 은 서식이 아닙니다.
  • 짝 없는 기호는 글자 그대로 남습니다. 각주 표시 1.31** 를 그냥 써도 됩니다.
  • 기호를 글자로 쓰려면 앞에 \ 를 붙입니다: \*\*, \{빨강}, \<br>.
  • 제목과 그림 설명에는 서식을 쓰지 않습니다.

표

  • 구분선(|---|) 위가 머리글입니다. 머리글은 여러 줄일 수 있고, 표가 쪽을 넘어가면 다음 쪽에 다시 나옵니다.
  • 구분선으로 열 정렬을 정합니다: :--- 왼쪽, :---: 가운데, ---: 오른쪽.
  • 칸 합치기: 칸에 < 만 있으면 왼쪽 칸과, ^ 만 있으면 위 칸과 합칩니다. 행마다 칸 수는 그대로 둡니다. 머리글과 본문은 따로 합치고, 합친 모양이 직사각형이 아니면 합쳐지지 않습니다.
  • 칸 배경: 칸 내용 전체를 {음영}…{/음영} 으로 감쌉니다.
  • 칸 안의 | 는 \|, 줄바꿈은 <br> 입니다. < 나 ^ 한 글자만 든 칸을 글자로 쓰려면 \<, \^ 로 씁니다.
  • 모든 행의 칸 수는 머리글과 같아야 합니다. 모자라면 빈 칸으로 채워지고, 넘치면 그 줄 번호와 함께 오류로 알려 줍니다.

그림

![설명](이름) 을 한 줄에 혼자 씁니다. 편집기에서 ‘그림’ 을 눌러 붙이면 이름이 자동으로 들어갑니다. 설명은 그림 아래에 나옵니다. 그림은 문서와 함께 브라우저에 보관됩니다.

쪽

  • 쪽은 PDF 를 실제로 그려 본 결과로 정해집니다. 화면 미리보기의 파란 점선(‘2쪽’)이 PDF 에서 쪽이 넘어가는 자리입니다.
  • 블록은 남은 자리에 안 들어가면 통째로 다음 쪽으로 갑니다. 한 쪽보다 큰 표는 행 단위로 나뉘고 머리글이 반복됩니다.
  • ‘문서 → 쪽 설정’ 에서 용지·방향·여백·글자 크기를 바꾸고, 큰 제목마다 새 쪽에서 시작하게 할 수 있습니다.
