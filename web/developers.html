개발자 안내

MDitor 는 MCP 서버와 HTTP API 를 엽니다. AI 에이전트나 내 프로그램이 Markdown 으로 문서를 쓰고, 문법을 검사하고, 쪽 배치를 확인하고, PDF 로 낼 수 있습니다. 웹 편집기와 같은 파서와 렌더러를 쓰므로 결과가 같습니다.

MCP 서버 연결

주소 하나만 등록하면 됩니다. 인증은 없습니다.

{origin}/mcp

Claude Code

claude mcp add --transport http mditor {origin}/mcp

설정 파일로 등록하는 클라이언트 (Claude Desktop, Cursor 등)

{
  "mcpServers": {
    "mditor": { "type": "http", "url": "{origin}/mcp" }
  }
}

전송 방식은 Streamable HTTP 입니다. 서버는 상태를 두지 않으므로 세션을 유지할 필요가 없습니다.

도구

도구하는 일
syntax_guide문법 전체를 돌려줍니다. 문서를 쓰기 전에 한 번 읽습니다.
check_markdown문서를 읽어 봅니다. 맞으면 뼈대(섹션·블록)와 표준 꼴 Markdown 을, 틀리면 줄 번호와 고칠 내용을 돌려줍니다.
page_layoutPDF 를 실제로 그려 보고 전체 쪽 수, 섹션·블록이 놓인 쪽, 긴 표와 목록이 넘어가는 자리를 돌려줍니다.
render_pdfPDF 를 만들어 내려받기 링크를 돌려줍니다(30분 뒤 지워집니다). 용지·방향·여백·글자 크기를 정할 수 있습니다.
diff_markdown고치기 전과 뒤를 블록 단위로 견줍니다. 새로 나온 숫자도 따로 알려 줍니다.
editor_link문서를 웹 편집기에서 여는 링크를 만듭니다. 내용은 주소의 # 뒤에 실려 서버에 저장되지 않습니다.

에이전트에게는 이렇게 시키면 됩니다.

MDitor 로 3분기 운영 보고서를 써 줘. 문법을 먼저 읽고, 다 쓰면 검사한 뒤 표가 쪽 중간에서 어색하게 잘리지 않는지 보고 PDF 로 내 줘.

HTTP API

MCP 없이 직접 부를 수도 있습니다. 본문은 JSON 이고 모든 호출은 저장하지 않습니다.

호출돌려주는 것
POST /api/md/preview되읽은 문서(JSON)와 표준 꼴 Markdown. 틀리면 {ok: false, error: {line, message}}
POST /api/md/preview-pages쪽 배치: 섹션·블록·항목·표 행이 놓인 쪽과 전체 쪽 수
POST /api/md/pdfPDF 파일. 쪽 수는 응답 헤더 X-Mditor-Pages
 
curl -X POST {origin}/api/md/pdf \
  -H "Content-Type: application/json" \
  -d '{"md": "# 보고서\n\n## 1. 요약\n\n- 첫 항목\n", "options": {"page": "A4"}}' \
  -o report.pdf

options 에는 page(A4·Letter), landscape, margin_mm(8~40), font_size(8~14), font(pretendard·nanum-myeongjo·nanum-gothic·nanum-pen), section_break, page_numbers 를 넣을 수 있습니다. 그림은 images 에 {이름: data URI} 로 보냅니다.

요청 머리글에 Accept-Language: en 또는 ko(기본)를 보내면 오류 메시지가 그 언어로 나옵니다. 태그가 아직 없는 문서에서 쓸 태그의 말({빨강} 또는 {red})도 이것으로 정해집니다.

공개 서비스라 요청 횟수와 문서 크기에 한도가 있습니다(문서 40만 자, 그림 합계 8MB). 한도를 넘으면 429 또는 413 으로 답합니다. 대량으로 쓰려면 직접 서버를 띄우세요.

내 컴퓨터에서 돌리기
