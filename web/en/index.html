Where the preview turns the page, so does the PDF

MDitor is a document editor for reports. You edit the document as it looks, and the source stays plain Markdown. The page breaks in the preview aren’t estimates: they’re where the PDF actually breaks, because MDitor renders the PDF to find them.

Two ways to edit the same document, two ways to check it

Edit on the left, check on the right. The left pane switches between Document and MD, the right pane between Preview and PDF. Whichever side you edit, the source is one and the same Markdown.

  • Edit it as it looks

    In the Document tab you write as you would in a word processor: add bold, underline and text color, drag across table cells to merge them, and align columns. When you paste from Word or Excel, only the formatting this document supports is kept.

    Switch to the MD tab and the same document appears as text. Merged cells are written with < and ^, text color with tags like {red}, all inside ordinary Markdown. So any Markdown viewer can still read it, and you can download it as a file and keep it anywhere.

  • No guessing where pages break

    Working out pages from screen height goes wrong, because fonts and line wrapping differ from the PDF. Every time you edit, MDitor has the server actually render the PDF, then shows in the preview which page each block and table row landed on. The blue dashed line marks the spot.

Frequently asked questions

Where are my documents stored?
Only in the browser you’re using. The server receives the text briefly to build the preview and the PDF, and doesn’t keep it. To move a document to another device, download it as an MD file.
Is it really free?
Yes. It’s supported by ads. There’s no sign-up and no payment.
What kinds of documents is it for?
Structured documents built from repeating headings, items and tables: work reports, plans, meeting minutes, project reports and the like. It isn’t a fit for documents that need a free-form page layout.
What happens when a table is longer than a page?
It splits between rows, and the header rows repeat on the next page. The preview shows which row it breaks at.
Which characters show up in the PDF?
English letters, digits and punctuation, all 11,172 Hangul syllables, 4,888 Hanja (Chinese characters), and the symbols common in reports (※ ① → ■ and so on). Pick the typeface in Page setup: Pretendard, Nanum Myeongjo, Nanum Gothic or Nanum Pen Script (all free fonts). Hanja and symbols the chosen font lacks are filled in from Pretendard.
What if I close the window without saving?
Your draft stays in the browser, so you can pick up where you left off when you come back. Every save also keeps a version, so you can go back to earlier content.
