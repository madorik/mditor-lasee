Where the preview turns the page, so does the PDF

MDitor LaSee is a document editor for reports. The source stays plain Markdown. The page breaks in the preview aren’t estimates: they’re where the PDF actually breaks, because LaSee renders the PDF to find them.

Two ways to edit the same document, two ways to check it

Edit on the left, check on the right. The left pane switches between Document and MD, the right pane between Preview and PDF. Whichever side you edit, the source is one and the same Markdown.

Frequently asked questions

What is MDitor LaSee?
A Markdown document editor for structured documents such as reports, plans and meeting minutes, built from repeating headings, items and tables. You can format text like a word processor or edit the Markdown source directly, and the page breaks in the preview match the PDF you download.
How do I convert Markdown to PDF?
In the editor, open an MD file with ‘File → Open file’ or drop it onto the window, then choose ‘Export → Download PDF’. The PDF breaks pages exactly where the preview shows.
Can I add images?
Yes. Use the ‘Image’ button in the toolbar to add PNG, JPEG, GIF or WebP files of up to 10 MB each. Uploaded images are deleted automatically after 3 days, so download documents you want to keep as PDF — the PDF contains the images.
Where are my documents stored?
Only in the browser you’re using. The server receives the text briefly to build the preview and the PDF, and doesn’t keep it. Only images you add are uploaded to image storage, where they are kept for 3 days. To move a document to another device, download it as an MD file.
What kinds of documents is it for?
Structured documents built from repeating headings, items and tables: work reports, plans, meeting minutes, project reports and the like. It isn’t a fit for documents that need a free-form page layout.
What happens when a table is longer than a page?
It splits between rows, and the header rows repeat on the next page. The preview shows which row it breaks at.
Which characters show up in the PDF?
English letters, digits and punctuation, all 11,172 Hangul syllables, 4,888 Hanja (Chinese characters), and the symbols common in reports (※ ① → ■ and so on). Pick the typeface in Page setup: Pretendard, Nanum Myeongjo, Nanum Gothic or Nanum Pen Script (all free fonts). Hanja and symbols the chosen font lacks are filled in from Pretendard.
What if I close the window without saving?
Your draft stays in the browser, so you can pick up where you left off when you come back. Every save also keeps a version, so you can go back to earlier content.
