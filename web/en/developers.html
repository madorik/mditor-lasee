Developer guide

MDitor LaSee offers an MCP server and an HTTP API. AI agents and your own programs can write documents in Markdown, check the syntax, verify the page layout, and export PDFs. They use the same parser and renderer as the web editor, so the results are identical.

Connecting the MCP server

Register a single URL. There’s no authentication.

{origin}/mcp

Claude Code

claude mcp add --transport http mditor {origin}/mcp

Clients configured with a settings file (Claude Desktop, Cursor, etc.)

{
  "mcpServers": {
    "mditor": { "type": "http", "url": "{origin}/mcp" }
  }
}

The transport is Streamable HTTP. The server is stateless, so there are no sessions to keep alive.

Tools

ToolWhat it does
syntax_guideReturns the full syntax. Read it once before writing a document.
check_markdownReads a document. If it’s valid, returns its structure (sections and blocks) and the canonical Markdown; if not, the line number and what to fix.
page_layoutActually renders the PDF and returns the total page count, the page each section and block lands on, and where long tables and lists break.
render_pdfBuilds the PDF and returns a download link (deleted after 30 minutes). Paper size, orientation, margins and font size are configurable.
diff_markdownCompares a document before and after a change, block by block, and lists any new numbers separately.
editor_linkMakes a link that opens the document in the web editor. The content travels after the # in the URL and is never stored on the server.

Write our Q3 operations report with MDitor. Read the syntax guide first. When you’re done, check the document, make sure no table gets cut awkwardly mid-page, and export it as a PDF.

HTTP API

You can also call it directly, without MCP. Request bodies are JSON, and nothing is ever stored.

CallReturns
POST /api/md/previewThe parsed document (JSON) and its canonical Markdown. On an error, {ok: false, error: {line, message}}
POST /api/md/preview-pagesPage layout: the page each section, block, list item and table row lands on, plus the total page count
POST /api/md/pdfThe PDF file. The page count is in the X-Mditor-Pages response header
 
curl -X POST {origin}/api/md/pdf \
  -H "Content-Type: application/json" \
  -H "Accept-Language: en" \
  -d '{"md": "# Report\n\n## 1. Summary\n\n- First item\n", "options": {"page": "A4"}}' \
  -o report.pdf

options accepts page (A4 or Letter), landscape, margin_mm (8–40), font_size (8–14), font (pretendard, nanum-myeongjo, nanum-gothic or nanum-pen), section_break and page_numbers. Send images in images as {name: data URI}.

Send Accept-Language: en or ko (the default) to set the language of error messages. It also sets the tag language ({red} or {빨강}) used for a document that has no tags yet.

This is a public service, so request rates and document sizes are limited (400,000 characters per document, 8 MB of images in total). Requests over the limit get a 429 or 413 response. For heavy use, run your own server.

Running it on your own machine

The source is at github.com/madorik/mditor-lasee. The local MCP server (stdio) writes PDFs straight to files and reads the image files a document refers to from disk. See the README in the repository for installation and usage.
